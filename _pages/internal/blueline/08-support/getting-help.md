Blueline is a newly configured **EVL project in testing**. Some failures or changes are expected; please report issues, software requests, and job failures in **Spear cluster Slack**.

For **initial access requests**, contact **Prof. Michael E. Papka** or **Prof. Zhiling Lan**. Account provisioning is handled by the project team. Users do not need to manage that process.

A higher-speed network upgrade is planned; the current network is **1 Gb**. Performance concerns may be especially relevant during this phase.

When reporting a problem, include:

- The time the issue occurred and what you were trying to do.
- The command or Slurm job script (remove any secrets).
- The Slurm job ID (if applicable).
- Any relevant error messages and output files.
- The compute node name, if relevant.

**Do not post** UIC passwords, SSH private keys, access tokens, or sensitive research data.

Use the **Spear cluster Slack** that project members already have access to; no specific channel/link is published in this guide. Service hours and escalation procedures are **TBD**.

**Reminder:** NFS home directories are **not backed up**. Keep an independent copy of important research data.
