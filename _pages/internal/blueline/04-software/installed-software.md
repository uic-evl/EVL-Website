## Confirmed Lmod module

| Package | Module name | Notes |
|---|---|---|
| MPICH | `mpich/5.0.2` | MPI implementation, available through Lmod |

Load it with:

```bash
module load mpich/5.0.2
```

Other application/compiler packages and their versions have **not been confirmed**. Do not assume that Python, Conda, GCC toolchains, R, or any particular scientific application is preinstalled or supported as a module.

For requests for additional modules/software, use the Spear cluster Slack support channel.
