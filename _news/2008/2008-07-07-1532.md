## Verification of Data Intensive High Performance Computing Middleware
**Vishwanath, V.,Zuck, L.**
- Location: Princeton, NJ
- URL: www.cs.utah.edu/ec2
- PDF: [vishwanath_ec2_2008.pdf](/documents/vishwanath_ec2_2008.pdf)

[![image](/images/anr_sm.jpg-srcw.jpg){:style="max-width: 100%"}](/images/anr_sm.jpg-srcw.jpg)

In this paper, we present our experiences with using verification techniques in Data Intensive High Performance Computing. We discuss the requirements from verification tools to be effectively used in high performance computing (HPC).

**Citation**: Vishwanath, V., Zuck, L., Verification of Data Intensive High Performance Computing Middleware, *Exploiting Concurrency Efficiently &amp; Correctly, (EC)2 Workshop held with 20th International Conference on Computer Aided Verification*, Princeton, NJ, 2008-07-07.
